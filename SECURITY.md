# Security

Morrow-Finance-Gob is a research build. It has not been audited, it is not deployed, and there is no bug bounty.

## Reporting

Please report a vulnerability privately by email to adiiiresearch@gmail.com or biradaraditya9712@gmail.com rather than in a public issue. Include the affected contract, the steps to reproduce (a Foundry test is ideal), and the impact you expect.

## Scope

The contracts under `contracts/src/`. Issues in Morpho Midnight or Morpho Blue themselves belong with Morpho; report them here only if the bug is in how Morrow uses them. The items listed under "Secondary in this build" in the README are known simplifications, not findings.
